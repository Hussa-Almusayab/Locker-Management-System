# 🛡️ Locker Management System
![Locker Management System Banner](Locker-Management-System.png)

## 🎓 Academic Context
This project is a graduation requirement for my **Diploma in Computer Software**. It serves as a practical application of software engineering principles, database management, and secure coding practices.

---

## 📖 Overview
The **Locker Management System** is a robust web application built to automate the management and tracking of physical lockers. Developed as part of the **Computer Software** curriculum, the system bridges the gap between efficient software logic and secure data handling, ensuring a seamless experience for both administrators and users.

---

## 🚀 Key Features
* **Locker Automation:** Full CRUD (Create, Read, Update, Delete) operations for locker management.
* **User Reservation System:** Simple and intuitive interface for locker booking.
* **Admin Dashboard:** Comprehensive oversight of locker statuses and user activities.
* **Automated Notifications:** Integration with **MailKit** for real-time email confirmations.
* **Responsive UI:** Optimized for all screen sizes using Bootstrap.

---

## 🛠️ Tech Stack & Software Skills
* **Programming Language:** C# (Back-end logic).
* **Web Framework:** ASP.NET Web Forms.
* **Database:** Microsoft SQL Server (Relational database design).
* **Frontend:** HTML5, CSS3, JavaScript, jQuery.
* **UI Framework:** Bootstrap 3.3.7.
* **Version Control:** Git & GitHub.

---

## 🛡️ Cybersecurity Integration
Applying my expertise in cybersecurity to my **Software Software Diploma** project:
* **Safe Data Handling:** Used Parameterized Queries to block **SQL Injection** attacks.
* **Input Validation:** Implemented server-side checks to prevent **XSS** and malicious injections.
* **Secure Auth:** Developed a secure logic for session management and user login.

As a designer, I implemented a **Minimalist Aesthetic** using a light-colored palette (Off-white and Tech Blue). The goal was to create a clean, professional software interface that prioritizes usability and reflects a modern tech environment.
