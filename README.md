# 🔒 Locker Management System

An automated full-stack reservation system designed to manage locker assignments efficiently and securely. This project was developed as part of my professional training to bridge the gap between software development and secure data management.

---

### 🚀 Technologies Used
* **Frontend/Application:** Java (Swing/JavaFX)
* **Backend Logic:** PHP
* **Database:** SQL (Structured Query Language)
* **Environment:** Full-stack integration for locker automation.

---

### ✨ Key Features
* **Automated Reservations:** Streamlined process for users to book and manage lockers without manual intervention.
* **Database Management:** Secure handling of user records and locker status using SQL.
* **Cross-Platform Integration:** seamless communication between the Java interface and PHP server scripts.
* **Security Focused:** Designed with data integrity and user privacy in mind.
