# 🛡️ Locker Management System
![Locker Management System Banner](Locker%20Management%20System.png)

A secure, full-stack automated locker management web application developed as a graduation project for the **Computer Software Diploma**, built with **C# / ASP.NET** and **Microsoft SQL Server**.

## 🎓 نبذة عن المشروع (Project Overview)
هذا المشروع هو متطلب التخرج لتخصص **دبلوم برمجيات الحاسب**. يهدف النظام إلى أتمتة إدارة الخزائن الجامعية وتسهيل عملية الحجز والتتبع والإشعارات البريدية بشكل آمن وفعال.

---

## 🛡️ الجانب الأمني (Cybersecurity Integration)
تم بناء النظام مع مراعاة معايير البرمجة الآمنة (Secure Coding Practices):
* **SQL Injection Prevention:** استخدام Parameterized Queries في جميع استعلامات قاعدة البيانات.
* **Input Validation & XSS Mitigation:** التحقق الصارم من صحة مدخلات المستخدم وتصفيتها لمنع هجمات XSS.
* **Secure Authentication & Session Management:** نظام تسجيل دخول آمن مع إدارة محمية للجلسات والصلاحيات (Role-Based Access).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Backend:** C# / ASP.NET Web Forms
* **Database:** Microsoft SQL Server
* **Frontend:** Bootstrap 3.3.7, HTML5, CSS3, jQuery
* **Automation:** MailKit لإرسال إشعارات البريد الإلكتروني التلقائية
